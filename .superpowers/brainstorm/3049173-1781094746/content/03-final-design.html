⚡ 性能优化方案

导航体验

  • 每个路由添加 loading.tsx 骨架屏 → 点击瞬间反馈
  • 启用 View Transitions API → 页面平滑过渡
  • 侧边栏用 <Link> 预加载 → hover 即开始加载目标页

数据更新

  • CRUD 操作用 useOptimistic → 先更新 UI 再等服务器
  • 用 startTransition 包裹 router.refresh() → 不阻塞交互
  • 仪表盘数据用 stale-while-revalidate → 先展示缓存再刷新
